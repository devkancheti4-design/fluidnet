Who decided · every bug

Ten bugs. Ten decisions. All of them the core's.

The core located, generated, judged and shipped all ten. On two of them it could not choose alone — two different fixes passed click's full suite — so it asked the suit for one fact each: a test, an input and its expected output. The core ran that test against both fixes and chose.

The contract

What the core does, and what the suit may do.

The core · fluidnet with buggy

  • →finds where — buggy's laws, a hive of workers when the target is large
  • →generates every candidate from taught vocabulary
  • →refuses candidates a property disproves, before any test runs
  • →certifies on the full suite, and ships only the one fix that passes
  • →when two pass, runs the suit's test against both and chooses

The suit · an AI agent

  • +hands in data: one test — an input and its expected output
  • +hands in vocabulary: a rule and its property, for a shape the core has never seen
  • −never writes a fix
  • −never decides what ships — a test it writes must separate the fixes, or the core ignores it
